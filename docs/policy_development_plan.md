# ახალი უსაფრთხოების პოლიტიკის შემუშავებისა და დანერგვის გეგმა

## 1. პოლიტიკის დოკუმენტის შექმნა და გადამოწმება
- **მიზანი:** პოლიტიკა უნდა აღწერდეს პლატფორმაზე ინფორმაციის დაცვას, მომხმარებლის უფლებების მართვას და ინციდენტების რეაგირების წესებს.
- **მოთხოვნების იდენტიფიკაცია:**
  - შეაგროვეთ რეგულაციური მოთხოვნები (GDPR, ადგილობრივი მონაცემთა დაცვის კანონმდებლობა).
  - განსაზღვრეთ შიდა ოპერაციული მინიმუმები: ავტენტიკაცია, ავტორიზაცია, ლოგირების სქემა, მინიმალური დაშიფვრის სტანდარტები.
  - ჩართეთ პროდუქტისა და ოპერაციების გუნდები პროცესში, რათა გაიგოთ დომენის სპეციფიკური მოთხოვნები.
- **ცვლილებების მენეჯმენტი:**
  - ჩამოწერეთ ცვლილებების ინიცირების, განხილვის და დამტკიცების სტადიები.
  - განსაზღვრეთ ვერსიის კონტროლის პროცესი (მაგ., Git რეპოზიტორიაში ცვლილებების მოთხოვნის ფორმატი, change log-ის განახლება).
  - შექმენით ცვლილებების საბჭოს (CAB) შეხვედრის კალენდარი და პასუხისმგებელი პირები.
- **იურიდიულ და უსაფრთხოების გუნდთან გადამოწმება:**
  - მოამზადეთ ნასვენი ვერსია და გაუზიარეთ იურიდიულ გუნდს შესაბამისობის რისკების შესაფასებლად.
  - უსაფრთხოების გუნდთან ერთად განიხილეთ ტექნიკური კონტროლები და შესაბამისი მონიტორინგის მექანიზმები.
  - დაიფიქსიროს ყველა კომენტარი და გადაწყდეს პასუხისმგებელი პირი თითოეული შენიშვნის დასახურად.

## 2. გუნდის პრეზენტაცია და ვორქშოფი
- მოამზადეთ 30-45 წუთიანი პრეზენტაცია პოლიტიკის მიზნების, ძირითადი მოთხოვნებისა და როლების შესახებ.
- დაამატეთ პრაქტიკული ქეისი/ვორქშოფის ნაწილი, სადაც გუნდები იმუშავებენ პოლიტიკის გამოყენების მაგალითზე (მაგალითად, ინციდენტის მოხსენების სცენარი).
- მოიძიეთ უკუკავშირი პრეზენტაციის ბოლოს ონლაინ ფორმის ან Q&A სესიის საშუალებით.
- დაინიშნოს ერთობლივი ჩანაწერის სივრცე (Miro/Confluence/Notion), სადაც მონაწილეები შემდგომში დააფიქსირებენ დამატებით მოსაზრებებს.

## 3. საბოლოო ვერსიის დამტკიცება, გავრცელება და მონიტორინგი
- დაიფიქსიროს ვერსიის საბოლოო ნომერი, დამტკიცების თარიღი და დამტკიცების პასუხისმგებელი პირები (CTO, CISO, იურიდიული ხელმძღვანელი).
- გაავრცელეთ პოლიტიკა შიდა არხებში:
  - განათავსეთ დოკუმენტი კომპანიის Wiki/Confluence-ში;
  - გამოაგზავნეთ მოკლე შეჯამება ელფოსტით ან Slack არხში შესაბამისი გუნდის მიხედვით.
- მონიტორინგის მეთოდები:
  - განახორციელეთ ყოველთვიური შემოწმება ცვლილებების ჟურნალი და შესაბამისობის მეტრიკები;
  - დანერგეთ ობიექტური მაჩვენებლები (კონტროლების შესრულების %, ინციდენტების რეაგირების დროში შემცირება);
  - ჩართეთ შინაგან აუდიტს კვარტალური გადამოწმებისთვის.
- განაახლეთ პოლიტიკა ყოველწლიურად ან მნიშვნელოვანი ცვლილებებისას და გამოიყენეთ ცვლილებების მენეჯმენტის პროცედურა ახალი ვერსიებისათვის.
